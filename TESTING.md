# CampusShare — Testing Instructions
1. Open `index.html` in a modern browser.
2. Student view > Discover > DSLR Camera Kit > Request resource.
3. Purpose `Photography for campus fest`; select a slot; duration `2 hours; return by 5 PM`; submit.
4. Staff view > approve the request.
5. Student view > My bookings > Check in / collect. Enter `Good; no visible damage`.
6. Return resource. Enter `Returned in good condition`; choose No to issue prompt.
7. Open Activity history and confirm the steps are recorded.
8. Repeat a request for the same resource/slot to demonstrate conflict/waitlist handling.
9. For an incident test, check out a resource and report an issue on return; staff view can review it.
All data is fictional. No real authentication exists. Do not enter real personal data.
